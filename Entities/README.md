# Entities

Canonical copies of the currently labeled CEntities decompilation files.

- `index.csv` lists the general CEntities files in this folder.
- `all_entities_index.csv` lists both general CEntities and level-specific entries.
- `WelcomeToTheJungle\` contains level-specific WelcomeToTheJungle entity functions.

Generated from `ghidra_export\labels_effective.csv` and `ghidra_export\decomp`.
